# Numbers from code, words from AI

Every number the person sees (invested, value, fund move, market move) is worked out in code from NAVs. The AI only writes the words around a fixed set of facts it is given, and code checks every number in its reply against those facts. If any number does not match, the person sees a plain template with the same facts instead. A wrong number about someone's own money is the worst failure this product can have, and language models make arithmetic slips.

## Considered options

- Let the AI work out the numbers too. Rejected: we could not check them.
- Templates only, no AI. Rejected: a template cannot answer a person's own follow-up question in Hinglish. That is where the AI earns its place, and the template stays as the safe version.
